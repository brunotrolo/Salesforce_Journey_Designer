# Specs de jornadas

Uma pasta por jornada: `specs/<NNN>-<slug>/{spec.md, plan.md, tasks.md}` (+ `data-mapping.md`/`research.md` quando aplicável).

- `NNN` é sequencial e reservado em `docs/sdd/BACKLOG.md` — não crie uma pasta aqui sem primeiro adicionar/confirmar a linha correspondente no backlog.
- Gerado e mantido pelos agentes em `.claude/agents/` (ver `.claude/agents/README.md`).
- Templates de origem: `.claude/skills/spec-kit/templates/{spec,plan,tasks}-template.md`.
